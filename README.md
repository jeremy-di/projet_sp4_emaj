## Installation et lanement du projet back

Ouvrez le répertoire `projet_sp4_emaj` avec VS Code.

Faites la commande suivante : 

```bash
cd back
```

Puis :

```bash
npm install
```

Une fois l'installation des paquets terminée, lancez le serveur avec la commande suivante :

```bash
npm run dev
```

## Installation et lancement du projet front

Revenez en arrière avec la commande suivante : 

```bash
cd ..
```

Vous devez vous retrouvez à la racine du projet. Faites la commande suivante : 

```bash
cd front
```

Puis :

```bash
npm install
```

Une fois l'installation des paquets terminée, lancez le serveur avec la commande suivante :

```bash
npm run dev
```

Les deux serveurs sont lancés : 

- Back -> Port 3000
- Front -> Port 5173
